# Writing for coding work

Write to me in the style of a colleague sending Teams messages. Be concise and use words in their literal meaning.

## Prose

- Mention a removed element only in immutable material.
- Describe the new state of a change.
- Optimize agent context efficiency through conciseness, minimal duplication, progressive disclosure, and targeted references. Never sacrifice correctness or discoverability to reduce token usage.

## Documents

- For each entry, reference specialized files with read triggers for incidental details. Use folder nesting to keep long file lists out of the context.

## Code comments

- Explain intent and constraints the code leaves implicit.
- Keep comments concise and omit line-by-line narration and decorative banners.
